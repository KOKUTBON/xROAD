# Data and output licensing

This file separates the license for xROAD source code from the terms that apply to data and generated results.

## Source code

The source code in this repository is released under the [Apache License 2.0](LICENSE). Keep the license and applicable attribution notices when redistributing the code or derivative works.

## Dataset licenses

This public repository does not redistribute row-level crash data, private municipality exports, production databases, restricted geospatial datasets, paid datasets, or trained private model artifacts. The empty `data/` layout is intentional.

Before using a dataset locally, record its provider, version, download date, license, attribution text, geographic and temporal scope, and redistribution restrictions in your own data inventory. A source being publicly downloadable does not by itself grant permission to redistribute derived row-level data.

Synthetic examples generated by the demo tools are released under the Apache License 2.0 unless a generated file states otherwise.

## OpenStreetMap and ODbL

If OpenStreetMap data is used to build local features, comply with the [OpenStreetMap ODbL](https://www.openstreetmap.org/copyright) and the [OpenStreetMap Foundation licence](https://osmfoundation.org/wiki/Licence). Preserve the required attribution, identify the relevant data source, and assess whether a database or derivative database must be shared under ODbL. Do not publish restricted joins that expose protected source records merely because the map layer is public.

## Generated aggregate outputs

Aggregate maps, tables, metrics, and model reports are not automatically covered by the source-code license. Their terms depend on the input datasets, the transformation, and any provider restrictions. Publish only outputs that are sufficiently aggregated and approved for release; include source attribution, transformation date, methodology, and any applicable dataset licence. If all inputs permit it and no third-party terms override it, synthetic or wholly original aggregate outputs may be released under Apache-2.0.

## Attribution checklist

For every public data-backed result, include:

1. the dataset name, provider, version, and access date;
2. the exact licence and attribution wording;
3. the geographic and temporal coverage;
4. the transformations and aggregation threshold used;
5. a statement that no restricted row-level records are redistributed.

Questions about a dataset's terms should be resolved with the provider or rights holder before publication.
