# xROAD brand standard

Use the Signal road-warning mark from the active web application for repository documentation, application icons and generated reports.

- Canonical vector: [`apps/web/public/brand/road-accidents-risk-modeling-icon.svg`](../../apps/web/public/brand/road-accidents-risk-modeling-icon.svg).
- Raster variants live beside that vector. The dashboard uses the same identity under `dashboard/brand/`.
- The README uses the canonical application vector. Preserve its proportions and amber/asphalt palette.
- Current colors, typography, themes and component usage are documented in [the Signal design system](road-intelligence-design.md).

Retain third-party font files and their license notices when packaging the application. Do not reintroduce abandoned crown or letter-based marks.
